# TBR Jar

A polished, dependency-free To-Be-Read jar built with HTML, CSS and vanilla JavaScript.
The TBR jar is meant to be used by me and my sister when havint trouble choosing our next read.

## Features
- Add and remove prompts
- Random "Shake the jar" picker
- Persistent browser storage with `localStorage`
- Light/dark theme
- Responsive layout
- No backend, build step, or server required
